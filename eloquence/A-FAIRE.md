(screenshot t14_streak_screen.png). A reload afterwards does not repair it. The same root cause also stops the daily reminder toast (dailyNudges, app.js:165-174) and quest/goal refresh from running when the app resumes.
- Correction proposée : In store.js S.touchStreak, call `var n = S.checkStreak();` before computing the gap, so freezes are applied or the loss is recorded first, and return n so lesson.js can show it. In app.js boot(), record `lastDay = U.dayKey()` and add `document.addEventListener('visibilitychange', ...)` plus a `focus` listener. When the page becomes visible and U.dayKey() !== lastDay, run `streakToast(Store.checkStreak()); Store.quests(); App.render(); dailyNudges();` and update lastDay. Skip this when App.Lesson.active() is set.
